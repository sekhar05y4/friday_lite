FRIDAY Lite AI Assistant

A fast, lightweight, modular personal AI assistant built with Flutter Clean Architecture, Python Flask AI Backend, and a local-first offline command router.

View GitHub Source Code

⚡ Local-First Command Router

20 local action modules handle phone calls, SMS, contacts, app launching, notes, reminders, alarms, to-do lists, and device controls with zero network latency.

🔋 Strict Power Mode

Zero resource consumption when OFF. Completely releases microphone, background timers, and AI processing until explicitly enabled by the user.

👁️ Camera Vision Platform

Decoupled frame processing pipeline supporting QR/Barcode scanning, OCR document text reading, face detection, and object detection.

🧠 Long-Term Memory System

Stores facts, preferences, knowledge, relationships, and task memories in SQLite with ranking and expiration logic.

💻 Desktop Companion System

Authenticated Python companion service for remote PC control (Windows, Ubuntu, macOS): screenshots, terminal execution, volume control, and clipboard sync.

📴 Offline Local LLM Provider

100% offline inference engine supporting Ollama and llama.cpp for offline chat, intent classification, text summaries, and reasoning.
